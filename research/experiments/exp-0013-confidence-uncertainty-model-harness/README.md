Purpose: add explicit uncertainty semantics after reference integrity, semantic support, multi-hop derivation and temporal validity.

## Core invariant

support != certainty

A claim can be:

- evidence-backed;
- semantically supported;
- temporally valid;

and still carry material uncertainty.

Confidence must never turn a non-canonical intelligence claim into canonical truth or executable authority.

## Dimensions

- source reliability;
- measurement quality;
- temporal quality;
- derivation depth;
- disagreement / contradiction;
- explicit unknowns.

## Decisions

- HIGH_CONFIDENCE
- MEDIUM_CONFIDENCE
- LOW_CONFIDENCE
- INSUFFICIENT_INFORMATION
