# Economic Decision Room

The Decision Room is Flooow's first visible decision surface:

```text
Economic Truth -> Sales Intelligence -> Decision Surface
              -> governed Intelligence -> Authority -> Execution
              -> Reconciliation -> Learning
```

TASK-0157 implements only the decision surface. The web application is
replaceable and does not become a new source of truth. The durable institutional
moat is the accumulated history of canonical truth, evidence, decisions and
outcomes, not a frontend framework or a generated recommendation.

The UI therefore communicates what Flooow knows, what remains missing, and when
the governed backend was refreshed. It does not claim closed-loop autonomous
decisioning, does not grant authority, and does not mutate marketplace state.
